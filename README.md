# Alice Huang, Photographer

One-page portfolio site for a freelance wedding and portrait photographer: hero with a contact button, a six-image portfolio grid, a short about section, and an email contact block.

## Files

- `project/Main.dc.html`: the page, with its markup, styles and a small background-colour tweak.
- `project/canvas.json`: canvas layout for the Claude Design editor.
- `images/wedding-1.png`: the first portfolio photo. In the Claude Design artifact it is served from an uploaded asset, so the `<img>` in `Main.dc.html` points to a `/_blob/` URL that only resolves there.
